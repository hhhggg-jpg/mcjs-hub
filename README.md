# mcjs-hub

MC 网页版 · 全版本智能选线跳转站

> 本站为**独立选线导航站点，并非 MCJS 官方网站**，仅提供线路测速、最优线路选择与跳转导航，不托管、不存储、不修改任何游戏文件，所有游戏内容均跳转至 MCJS 官方及第三方公开节点。

## ✨ 功能介绍

- **全版本覆盖**：官方稳定版（1.8.8 JS/WASM、1.12.2 JS/WASM）、第三方客户端（PixelClient、TuffClient）、模组整合包、怀旧旧版（1.6.4 ~ Alpha 1.2.6）、实验性高版本（1.14.4 ~ 26.2 WASM）共 25 个版本入口
- **智能选线**：11 条稳定线路一键测速，按延迟与国内可达性排序，**由用户手动点击线路后再跳转**，绝不自动跳转
- **后台预热**：页面加载后对最优线路进行轻量预载，弱网/省流量自动降级为仅测延迟
- **探索面板**：全版本 × 全线路延迟矩阵、实验参数（快速测速 / 深度预热 / 紧凑模式 / 减少动画 / 并发调节）
- **本地数据**：收藏置顶、最近使用、线路黑名单、版本备注、测速历史、数据备份导出 / 恢复——全部仅保存在本机浏览器

## 🚀 部署说明

单文件静态页面项目（`index.html` 含全部 CSS/JS，零外部依赖），可直接部署于任意静态网页托管平台：

- **EdgeOne Pages（主站）**：https://mcp.edgeone.site/share/jeU3JR2SQM61buyKveMus
- **GitHub Pages（源码备份）**：上传 `index.html` 至仓库根目录，Settings → Pages → 部署分支 `main` / 根目录
